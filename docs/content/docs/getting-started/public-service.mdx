---
title: 连接公共服务
description: 无需 DashScope key，把公共 ICML MCP 注册到客户端并完成第一次搜索。
---

公共实例适合快速验证工具和轻量调研。客户端不需要提供 DashScope key。

## 注册 Claude Code

```bash
claude mcp add --transport http icml-papers --scope user \
  https://icml.agent4sci.com:20441/mcp
```

确认服务已经注册：

```bash
claude mcp list
```

其他兼容 MCP 的客户端使用以下配置：

```json
{
  "mcpServers": {
    "icml-papers": {
      "type": "http",
      "url": "https://icml.agent4sci.com:20441/mcp"
    }
  }
}
```

## 第一次调用

让客户端调用：

```text
search_papers(query="discrete diffusion language models", top_k=5)
```

这是无状态搜索。需要连续换词且不重复论文时，先创建 session：

```text
open_search_session(label="diffusion LM", default_top_k=5)
search_papers(query="masked diffusion text", session_id="...")
```

## 公共实例边界

- 匿名共享，不提供 SLA。
- 每个来源 IP 和全局都有速率、日额度与排队上限。
- 共享 NAT 下的多人会共用同一 IP 配额。
- `session_id` 是 bearer capability；不要公开、记录或提交它。
- query 和 session 标签不得包含 secret、个人信息或未公开内容。

遇到 `rate_limited` 或 `server_busy` 时等待后重试；遇到 `budget_exhausted` 或 `embedding_quota_exhausted` 时，继续重试不会立即恢复服务。完整分类见[错误码](/docs/reference/errors)。
