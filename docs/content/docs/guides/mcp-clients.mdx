---
title: 配置 MCP 客户端
description: 在 Claude Code 与其他支持 Streamable HTTP 的客户端中注册服务。
---

服务只暴露 Streamable HTTP MCP，默认路径为 `/mcp`。健康检查是普通 HTTP 路由，不属于 MCP tool。

## Claude Code

公共实例：

```bash
claude mcp add --transport http icml-papers --scope user \
  https://icml.agent4sci.com:20441/mcp
```

本地实例：

```bash
claude mcp add --transport http icml-papers --scope project \
  http://127.0.0.1:20441/mcp
```

`user` scope 适合跨项目复用；`project` scope 适合把本地服务约束在当前仓库。

## 通用 JSON 配置

```json
{
  "mcpServers": {
    "icml-papers": {
      "type": "http",
      "url": "http://127.0.0.1:20441/mcp"
    }
  }
}
```

客户端必须支持 Streamable HTTP transport。不要把 `/health/ready`、Nginx 上游地址或容器内部 hostname 当作 MCP URL。

## 反向代理后的 URL

公网 URL 必须与应用 `allowed_hosts`、`allowed_origins` 和 TLS 证书一致。应用只有在 peer 位于 `trusted_proxy_networks` 时才接受代理写入的来源 IP header。

如果客户端报 Host/Origin 拒绝：

1. 确认 URL 的 scheme、host 和 port。
2. 检查代理是否保留正确 Host。
3. 把精确外部 origin 加入配置，不使用泛域名通配。
4. 用 `/health/live` 区分 TLS/代理问题与 MCP 初始化问题。

## Session 使用提醒

MCP transport session 与业务 `session_id` 不是同一个概念。前者由协议管理连接，后者由 `open_search_session` 返回并用于论文去重；不要互换。
