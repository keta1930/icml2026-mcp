---
title: 设计高质量调研流程
description: 用主题分解、query 变体和 session 边界提高论文发现覆盖率。
---

高质量检索不依赖一个“完美 query”，而是把研究问题拆成多个互补方向，并让同一 session 消除它们之间的重复结果。

## 先定义 session 边界

一个 session 对应一个可解释的研究目标，例如“LLM 推理优化”或“多模态 agent 评测”。主题过宽会让 seen 集合过早吞掉后续子任务的论文；主题过窄则失去跨 query 去重价值。

## 组织 query 组合

依次覆盖四种视角：

1. **任务**：系统要解决什么问题。
2. **方法**：具体模型、算法或训练策略。
3. **约束**：效率、鲁棒性、隐私、数据稀缺等。
4. **评测**：benchmark、metric、failure mode。

例如研究 LLM inference：

```text
efficient large language model inference
speculative decoding and verification
KV cache compression or eviction
latency throughput serving benchmark
```

## 用状态决定下一步

每轮关注新命中数、重复抑制数、候选窗口和连续空轮：

- 重复很多但仍有新命中：方向有效，继续细化。
- 窗口已满但新命中不足：换词或增大 `search_depth`。
- 连续空轮：检查过滤是否过窄，再决定结束方向。
- 标题相关但摘要偏离：引入更具体的方法名或约束词。

## 分开探索与筛选

探索阶段使用较宽 query 和较少过滤；筛选阶段再加入 `area`、`paper_type`、spotlight 或 `min_score`。过早叠加过滤会把“没有候选”和“候选已被 session 看过”混在一起。

## 结束与交接

关闭 session 前获取带论文标题的状态汇总，再关闭 capability。汇总是有界的，适合交给后续 agent 继续阅读全文或分类，不应被当作完整研究结论。
