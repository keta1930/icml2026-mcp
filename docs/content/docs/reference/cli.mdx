项目安装两个 console scripts：`icml-papers` 管理索引与本地检索，`icml-paper-search-mcp` 启动 Streamable HTTP 服务。

## `icml-papers info`

```bash
uv run icml-papers info
```

输出数据目录、state 路径、embedding 契约、RRF 参数、当前版本和语料统计。它只检查 key 是否配置，不读取 secret，也不访问 provider。

## `icml-papers build`

```bash
uv run icml-papers build
uv run icml-papers build --execute --max-input-tokens <CAP>
```

| 参数 | 作用 |
|---|---|
| `--execute` | 确认发起 DashScope 调用并写索引 |
| `--max-input-tokens N` | 本次建库 Token 硬上限；execute 时必填 |
| `--resume` | 从匹配的完整 batch checkpoint 恢复 |

默认模式是零云 preflight。缺少 execute 或正数 cap 时不会付费建库。

## `icml-papers search`

单次搜索：

```bash
uv run icml-papers search "discrete diffusion language models"
```

交互搜索：

```bash
uv run icml-papers search
uv run icml-papers search --session
```

| 参数 | 作用 |
|---|---|
| `-k, --top-k` | 返回条数上限 |
| `-d, --depth` | 固定候选窗口深度 |
| `--area` | 按领域过滤 |
| `--type` | 按论文类型过滤 |
| `--spotlight` | 只返回 spotlight |
| `--session` | 交互模式启用 session 去重 |

命令行带 query 时始终是单次无状态搜索；`--session` 只影响无 query 的交互模式。

## `icml-paper-search-mcp`

```bash
uv run icml-paper-search-mcp
```

读取 `Settings`，启动单进程 Streamable HTTP 服务。默认监听 `127.0.0.1:20441`，MCP 路径是 `/mcp`。

## 退出码

`icml-papers` 成功返回 0；公开应用错误、无效参数或不满足建库门槛返回 2，并只向 stderr 写脱敏文本。未知异常不属于稳定 CLI 契约。
