当前版本专注 ICML 2026。长期工作围绕两条主线推进，同时保留可解释 score、费用边界和可复现索引生命周期。

## 提升检索稳健性

建立可复现的离线评测，覆盖同一研究意图的不同措辞、专有名词、过滤组合和 fixed window。改进应以稳定发现相关论文为目标，而不是把 weighted RRF score 描述成概率或跨 query 指标。

评测同时记录召回质量、延迟、Token 消耗和 session 去重行为，确保稳健性提升不绕过费用与资源治理。

## 扩展开放学术语料

在 ICML 之外接入更多开放学术数据源，包括其他重要 AI 会议。每个来源继续保留明确的 provenance、venue/year 隔离、完整 paper-id 指纹、manifest 契约与可回滚索引生命周期。

具体数据源、时间表和里程碑将在完成来源许可、字段映射与质量验证后确定；本页不承诺未经确认的会议清单或发布日期。
