ICML Paper Search MCP 让 AI Agent 可以检索一份包含 6,341 篇 ICML 2026 论文的固定快照。数据包括标题、作者、摘要、研究领域、论文类型和来源链接。

服务提供六个工具，覆盖论文检索、论文读取、语料信息和三项搜索会话操作。会话可以避免已经返回过的论文再次出现。

- 试用公共实例：[公共服务](/zh/docs/getting-started/public-service)
- 部署自己的实例：[本地部署](/zh/docs/getting-started/local-deployment)
- 查看完整参数：[MCP 工具](/zh/docs/reference/mcp-tools)

项目使用 MIT 许可证开源。长期方向是提高检索稳健性，并增加更多开放学术数据源。
