---
title: 公共服务
description: 将 MCP 客户端连接到公共实例。
---

服务地址：

```text
https://icml.agent4sci.com/mcp
```

Claude Code：

```bash
claude mcp add --transport http icml-papers --scope user \
  https://icml.agent4sci.com/mcp
```

通用 Streamable HTTP 配置：

```json
{
  "mcpServers": {
    "icml-papers": {
      "type": "http",
      "url": "https://icml.agent4sci.com/mcp"
    }
  }
}
```

公共实例的额度由所有用户共享，维护期间可能暂时不可用。需要独立服务或独立数据时，请使用本地部署。
