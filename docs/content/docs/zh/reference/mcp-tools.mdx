## 调用约定

- 所有工具都是 async MCP tools，`Context` 不进入公开 schema。
- 返回值是紧凑 text content，直接进入 agent context。
- 业务失败同样返回 text，格式为 `error[code]: message`。
- `session_id` 是业务 capability，不是 MCP transport session id。
- 未传 `session_id` 的 `search_papers` 保持无状态。

## 典型组合

```text
open_search_session -> search_papers (多次)
  -> search_session_status -> close_search_session
```

`get_papers` 可以独立调用；传入 session 时，实际找到的论文会原子登记为 seen。`list_paper_areas` 用于在搜索前发现可用过滤值。
