项目提供两个命令：`icml-papers` 用于索引和本地测试，`icml-paper-search-mcp` 用于启动 MCP 服务。

## `icml-papers info`

```bash
uv run icml-papers info
```

输出 Milvus 地址、当前 collection、模型、路径和语料统计。这个命令不会调用 DashScope。

## `icml-papers build`

```bash
uv run icml-papers build
uv run icml-papers build --execute --max-input-tokens <CAP>
```

| 选项 | 作用 |
|---|---|
| `--execute` | 确认发起 DashScope 调用并写索引 |
| `--max-input-tokens N` | 输入 token 上限；execute 时必填 |
| `--resume` | 从匹配的完整 batch checkpoint 恢复 |

第一条命令只做离线预检；第二条命令调用 DashScope 并写入 Milvus collection。参见[构建索引](/zh/docs/guides/rebuild-index)。

## `icml-papers search`

```bash
uv run icml-papers search "discrete diffusion language models"
```

| 选项 | 作用 |
|---|---|
| `-k, --top-k` | 返回条数上限 |
| `-d, --depth` | 固定候选窗口深度 |
| `--area` | 按领域过滤 |
| `--type` | 按论文类型过滤 |
| `--spotlight` | 只返回 spotlight |

不传 query 时进入交互模式；在交互模式加 `--session`，本次终端会话中已经返回的论文不会再次出现。

## `icml-paper-search-mcp`

```bash
uv run icml-paper-search-mcp
```

启动一个 Streamable HTTP 进程。默认地址是 `http://127.0.0.1:20441/mcp`。

## 退出码

`icml-papers` 成功时返回 0，已处理的应用或输入错误返回 2。
