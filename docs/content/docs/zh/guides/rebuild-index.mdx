---
title: 构建索引
description: 创建并验证 Milvus 论文 collection。
---

预检只读取本地语料，显示论文数量和保守的输入上限，不会调用 DashScope：

```bash
uv run icml-papers build
```

确定输入上限后再执行构建：

```bash
uv run icml-papers build --execute --max-input-tokens 10000000
```

命令按完整批次写入数据，检查 Milvus schema、索引、行数、论文 ID、向量维度和一次混合检索，最后写入 `.data/index/current.json`。

普通中断留下有效 checkpoint 时可以加 `--resume`。如果失败原因是供应商用量超过构建上限，应先检查原因，再不带 `--resume` 重新执行。
