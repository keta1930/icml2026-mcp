---
title: 备份
description: 自建实例需要保存的数据。
---

需要备份以下 Docker volume：

- `etcd-data`、`minio-data` 和 `milvus-data`：Milvus collection；
- `icml-index`：`current.json` 和构建 checkpoint；
- `icml-state`：会话、限流和 embedding 缓存。

备份 `icml-state` 前先停止 MCP 应用。Milvus 备份需要同时停止 Milvus、etcd 和 MinIO，或使用 Milvus 支持的备份方法。恢复时应把三个 Milvus volume 作为一组，再恢复 manifest 和运行状态 volume。
