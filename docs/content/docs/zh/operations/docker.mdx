---
title: Docker Compose
description: 服务、volume 和生产环境 profile。
---

参考部署同时使用两个 Compose 文件：

```bash
docker compose -f deploy/compose.yaml -f deploy/milvus.compose.yaml config
```

其中包含 MCP 应用、Milvus Standalone、etcd、MinIO 和可选的 Attu。Milvus 数据、索引 manifest 和 SQLite 运行状态分别保存在命名 volume 中。使用 `--profile tools` 可以启动 Attu。

`production` profile 会增加 TLS Nginx 服务。启动前需要在部署环境中设置准确的公共 host、origin、可信代理网段、证书路径和公开端口：

```bash
docker compose -f deploy/compose.yaml -f deploy/milvus.compose.yaml \
  --profile production up -d
```

应用使用单进程和有界线程，Milvus 通过服务接口处理并发读取。
