title: 索引契约
description: Milvus collection 可以提供服务的条件。

当前索引由一个 Milvus collection 和 `current.json` 组成。Manifest 记录语料哈希、完整论文 ID 指纹、embedding 模型与维度、Milvus 版本、距离度量和 RRF 融合方式。

Readiness 会检查：

- 源文件与 manifest 一致；
- collection 包含规定字段和 BM25 function；
- COSINE 与 BM25 索引配置正确；
- 行数和完整论文 ID 集合与 6,341 篇论文快照一致。

这些检查不会调用 DashScope。
