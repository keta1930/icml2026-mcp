The parameter table is generated from the FastMCP schema by `docs/scripts/generate_reference.py`. A documentation build refreshes it after a tool signature or Pydantic `Field` changes.

## Calling contract

- All tools are async MCP tools; `Context` is excluded from the public schema.
- Results are compact text content intended to enter agent context directly.
- Business failures also return text in the form `error[code]: message`.
- A business `session_id` is not an MCP transport session ID.
- `search_papers` is stateless when no `session_id` is supplied.

## Typical sequence

```text
open_search_session -> search_papers (repeated)
  -> search_session_status -> close_search_session
```

`get_papers` can run independently. With a session, papers actually found are marked as seen atomically. Call `list_paper_areas` before search to discover valid filter values.
