Copy `.env.example` to `.env` for local use. Explicit environment variables override `.env`; all names use the `ICML_PAPERS_` prefix.

## Secret

Set the key directly or through a file:

```dotenv
ICML_PAPERS_DASHSCOPE_API_KEY=
ICML_PAPERS_DASHSCOPE_API_KEY_FILE=/run/secrets/dashscope_api_key
```

The file takes precedence. Public deployments should use a read-only secret file. Invalid values or inconsistent combinations stop the process before startup.

## JSON environment values

Use JSON arrays for list settings:

```dotenv
ICML_PAPERS_ALLOWED_HOSTS=["papers.example.com:443"]
ICML_PAPERS_TRUSTED_PROXY_NETWORKS=["172.20.0.0/16"]
```

Use the exact public Host, Origin, and proxy network in production.
