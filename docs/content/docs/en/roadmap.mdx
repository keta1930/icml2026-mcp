---
title: Roadmap
description: Make paper retrieval more reliable and add more open scholarly sources carefully.
---

The project has two long-term priorities.

## More reliable retrieval

Build repeatable evaluations and improve results across paraphrases, specialized terms, and filters. Retrieval quality, latency, and embedding cost will be measured together.

## More open data sources

Add other open scholarly sources after checking licenses, metadata, identifiers, update methods, and data quality. Each paper must keep a clear source, and index builds must remain reproducible.
