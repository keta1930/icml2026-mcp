---
title: Design a Strong Research Workflow
description: Improve paper discovery with topic decomposition, query variants, and clear session boundaries.
---

Strong retrieval does not depend on one perfect query. Decompose the research question into complementary directions and let one session remove duplicates across them.

## Define the session boundary first

One session should represent an explainable research goal, such as “LLM inference optimization” or “multimodal agent evaluation.” A goal that is too broad lets the seen set absorb papers needed by later subproblems; a goal that is too narrow loses the value of cross-query deduplication.

## Organize query variants

Cover four perspectives:

1. **Task**: What problem should the system solve?
2. **Method**: Which model, algorithm, or training strategy matters?
3. **Constraint**: Efficiency, robustness, privacy, data scarcity, or another limitation.
4. **Evaluation**: Benchmarks, metrics, and failure modes.

For LLM inference, for example:

```text
efficient large language model inference
speculative decoding and verification
KV cache compression or eviction
latency throughput serving benchmark
```

## Let status guide the next step

After each round, inspect new hits, suppressed duplicates, the candidate window, and consecutive empty rounds:

- Many duplicates with some new hits: the direction is productive; refine it.
- A full window but too few new hits: rephrase or increase `search_depth`.
- Consecutive empty rounds: check restrictive filters before ending the direction.
- Relevant titles with off-target abstracts: add a more precise method or constraint.

## Separate exploration from filtering

Explore with broader queries and fewer filters. Add `area`, `paper_type`, spotlight, or `min_score` during selection. Filtering too early mixes up “no candidates” with “the session already saw the candidates.”

## Close and hand off

Before closing, request a status summary with paper titles, then close the capability. The bounded summary is useful for an agent that will read or classify papers next; it is not a complete research conclusion.
