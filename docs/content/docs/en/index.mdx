---
title: Overview
description: What the service contains and where to start.
---

ICML Paper Search MCP lets an AI agent search a fixed snapshot of 6,341 ICML 2026 papers. The snapshot contains titles, authors, abstracts, research areas, paper types, and source links.

The server exposes six tools: paper search, paper lookup, corpus metadata, and three search-session operations. A session prevents papers already returned in that session from appearing again.

- To try the shared instance, see [Public service](/en/docs/getting-started/public-service).
- To run your own instance, see [Local deployment](/en/docs/getting-started/local-deployment).
- For exact parameters, see [MCP tools](/en/docs/reference/mcp-tools).

The project is open source under the MIT license. Its long-term direction is better retrieval robustness and additional open scholarly sources.
